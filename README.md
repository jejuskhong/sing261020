# 노래랑 단어랑

어린이를 위한 한국어·영어 동요 탐색, 그림 단어 듣기, 복습 퀴즈 웹앱입니다.

## 실행

루트의 `index.html`을 브라우저에서 엽니다. 서버나 패키지 설치가 필요하지 않습니다. 외부 무료 음원과 웹 폰트를 불러올 때는 인터넷이 필요합니다.

## 포함된 기능

- 한국어 30곡·영어 30곡 편성 후보 탐색과 제목·언어·주제 필터
- 그림 단어 읽어 주기와 복습 퀴즈
- 무료 음원 연결 곡만 표시하는 필터
- 기기 내 음원 열기, 느린 재생, 구간 따라 부르기
- 브라우저 내 학습 기록 저장과 초기화

## 음원 현황

10개 곡 화면에 외부 무료 음원 9개를 연결했습니다. 가창·피아노·선율 예제를 구분하며 작은 별과 Twinkle은 같은 피아노 파일입니다. 한국 전래동요 2곡은 공식 무료 제공 페이지를 안내하며 나머지 48곡은 음원 준비 중입니다. 60곡 전체 가창 음원이나 가사 동기화가 완성된 앱은 아닙니다.

출처와 이용 조건은 앱 안과 `FREE_AUDIO_NOTES.md`, `noraerang/dist/free-audio.js`에 기록했습니다. 실제 외부 음원 재생·청취 및 모바일 브라우저 검수는 아직 완료되지 않았습니다.

## 파일

- `index.html`: CSS·JavaScript를 포함하는 단일 실행 파일
- `noraerang/dist/`: 분리된 HTML·CSS·JavaScript 소스
- `PRD.md`: 제품 요구사항
- `FREE_AUDIO_NOTES.md`: 무료 음원 출처·확인 범위

## 수정 후 빌드와 검사

Node.js가 설치된 환경에서:

```sh
cd noraerang
node build.cjs
node verify.cjs
```

`build.cjs`가 루트의 단일 `index.html`을 다시 만듭니다. `verify.cjs`는 카탈로그, 필터, 퀴즈, 음원 매핑, 출처와 단일 파일 구성을 검사합니다. 브라우저 재생 검사를 대신하지 않습니다. `audio-update.cjs`는 이미 적용한 일회성 변경 기록이므로 재실행하지 않습니다.
